Las figuras de `needfinding/` son equivalentes visuales para el informe, **no exportaciones de UXPressia**. `event-storming/big-picture-final` es el tablero final de la propuesta documental, **no una captura de Miro ni evidencia de un taller validado**. Para reemplazar por UXPressia/Miro:

1. Importar o reconstruir los campos y notas usando el SVG o las tablas del informe.
2. Mantener la referencia a E1, las etiquetas E/I/N/D y las limitaciones de cada figura. El caso E1 no debe contarse como dos participantes.
3. Exportar PNG legible y reemplazar el archivo homónimo, o actualizar la ruta relativa en `docs/02-capitulo-2.md`.
4. Agregar el enlace público real del tablero y actualizar el pie de figura solo después de comprobar la exportación. Conservar el SVG como fuente histórica o actualizarlo para evitar divergencias.
5. Si se celebra un taller, documentar fecha, participantes, acuerdos y puntos pendientes; no reutilizar esta elaboración documental como acta.

## Evidencia y alcance

La única fuente de entrevista utilizada es el resumen de E1 en 2.2.2; no se verificó el contenido del video. E = explícito en ese resumen; I = interpretación pendiente; N/D = no documentado. Las prioridades cualitativas y emociones inferidas no son puntuaciones ni citas del participante. Las figuras no incluyen retratos ficticios.

El EventStorming es To-Be; sus reglas técnicas se remiten a US03–US19, TS01–TS06 y capítulos IV–V. Los flujos As-Is de Needfinding no incorporan esas funciones como prácticas actuales. El orden de flechas es causal por carril; los circuitos de riego y plagas pueden coexistir. La tabla del informe desarrolla excepciones que el tablero resume.
